To perform an analysis of whether positive or negative selection is occurring at different codons along BamA, we used the fixed-effects likelihood (FEL) tool within the HyPhy software package to estimate dN/dS ratios while examining 195 branches/nodes in our bacterial species tree. We used the alignment and tree file in this directory (codon_align.phy and pruned_tree.tre). Results can be found in the HyPhy_FEL_output.txt file (including the parameters used and the values for the statistically significant codons). We need to link the codon positions to the actualy amino acid alignment, this way we can connect these results to the protein structure of BamA and the bar charts (where we calculated the proportion of conservation along the gene as a whole).
